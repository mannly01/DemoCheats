# DEMO CHEATS
A collection of cheats for the Car Mechanic Simulator 2027 Demo.

## REQUIREMENTS
* [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3)

## UPDATE - 2.0.0
* Updated all features for the multiplayer demo.
* Some features only work on the host while in a multiplayer session and are labeled below.

## FEATURES
* (TransferAll) Move all items between the Player Inventory and a Warehouse with one key press (K) (SP ONLY)
* (TransferAll) Adjust the minimum condition of parts to move between 0 and 100% (-/=) (SP ONLY)
* (TransferAll) Set a maximum number of parts to move before a warning message is displayed (SP ONLY)
* Set the Inventory to unlimited for the Player and Warehouses (Warehouse UI won't show unlimited) (HOST ONLY)
* Move all items from the Shopping List to Shopping Cart with one key
* Add a configured amount of money and XP to the player
* Add skill points to the player
* Max out the skills of the player (this is permanent without saving)
* Toggle fast mounting of parts
* Change the Game Speed
* Change the Player Walk Run Speed (HOST ONLY)
* Paint the car and wheels an approved factory color by looping through the available ones (HOST ONLY)
* Repair the body parts to 100% when looking at a car (HOST ONLY)
* Spawn the 7 available Demo cars (with or w/o random condition) (HOST ONLY)
* **Maximum 10 cars allowed in the Demo**
* Refresh the Used Parts Market immediately
* Toggle showing only the DNB Censor car parts in the Used Parts Market
* Toggle the Demo World Limits to view more of the map (HOST & CLIENT REQUIRED)
* Delete a car (HOST ONLY)

## DEFAULT KEYS
* 'ACCEPT': Long press while the Shopping List is open to move all items to the Shopping Cart
* *^This is the key already assigned to ACCEPT in the game settings*
* R: Opens the Demo Cheats menu
* None: Cycle through the factory colors and paint the car (HOST ONLY)
* None: Repair the body parts to 100% (HOST ONLY)
* K: (TransferAll) Move all items from Inventory/Warehouse to opposite tab in Inventory screens. (SP ONLY)
* -: (TransferAll) Lower the part condition to move by 10%. This value is saved in MinPartCondition value on exit. (SP ONLY)
* =: (TransferAll) Raise the part condition to move by 10%. This value is saved in MinPartCondition value on exit. (SP ONLY)

## DEFAULT SETTINGS (DemoCheats.cfg)
* OpenCheatMenu: R
* PaintCar: None
* RepairBody: None
* MoneyAmount: 1000000
* XPAmount: 1000
* GameSpeedRate: 0.25
* RandomPartConditionOnSpawn: true (false = 100%)
* GameSpeed: 1.0
* WalkSpeed: 3.0
* RunSpeed: 5.0
* FastMount: false
* UnlimitedInventory: false
* TransferAllItems: K (TransferAll)
* SetPartConditionLower: - (TransferAll)
* SetPartConditionHigher: = (TransferAll)
* MinPartCondition: 0 (TransferAll)
* MinNumOfItemsWarning: 201 (TransferAll)
- [Keycode Values](https://docs.unity3d.com/ScriptReference/KeyCode.html)

## INSTALLATION (Same as all other MelonLoader mods)
* Install [MelonLoader 0.7.3](https://github.com/LavaGang/MelonLoader/releases/tag/v0.7.3) ([MelonLoader.Installer.exe](https://github.com/LavaGang/MelonLoader/releases/download/v0.7.3/MelonLoader.Installer.exe) recommended)
* Download .zip from [Releases](https://github.com/mannly01/DemoCheats/releases/latest) page
* Unzip the DemoCheats.dll file to Car Mechanic Simulator 2027 Demo\Mods folder
* **The DemoCheats.cfg file is optional but will allow you to edit the default settings**
- Default Folder: \SteamLibrary\steamapps\common\Car Mechanic Simulator 2027 Demo\Mods\
